# Entaxy

**https://entaxy.frlab.eu**

[Ελληνικά](#ελληνικά) · [English](#english)

## Ελληνικά

Το Entaxy είναι μια απλή εφαρμογή διαχείρισης τάξης για εκπαιδευτικούς. Κρατά το
ολοκληρωμένο μητρώο της τάξης: τα παιδιά, τα πρόσωπά τους και τα στοιχεία επικοινωνίας
τους. Η εφαρμογή είναι στα ελληνικά και στα αγγλικά.

### Τάξεις και παιδιά

- Μία ή περισσότερες τάξεις, η καθεμία με τα στοιχεία των παιδιών της: προσωπικά
  στοιχεία, διευθύνσεις, τηλέφωνα και σημειώσεις
- Για κάθε παιδί, τα πρόσωπά του, η σχέση τους με το παιδί και τα στοιχεία επικοινωνίας
  τους
- Μια τάξη μπορεί να κλειδωθεί από το μενού Τάξη: τα παιδιά της δεν προστίθενται, δεν
  αλλάζουν και δεν αφαιρούνται μέχρι να την ξεκλειδώσετε από το ίδιο μενού. Ένα λουκέτο
  δίπλα στο όνομά της δείχνει ότι είναι κλειδωμένη. Το όνομα της τάξης αλλάζει κανονικά

### Αναφορές

- **Πίνακας επικοινωνίας (pdf)**: έτοιμος για εκτύπωση κατάλογος της τάξης, με τα
  τηλέφωνα όλων των προσώπων κάθε παιδιού
- **Email προσώπων (csv)**: οι διευθύνσεις email των προσώπων, χωρίς διπλότυπα, έτοιμες
  για λίστα αποδεκτών

### Κάρτες

- **Πίνακας μαθητών (pdf)**: τα ονόματα των παιδιών σε πλέγμα για εκτύπωση και κόψιμο σε
  κάρτες, με 1, 2 ή 3 ονόματα ανά σειρά, προαιρετικά με το επώνυμο, με έντονα γράμματα ή
  τυπωμένο δύο φορές
- **Λίστα μαθητών (pdf)**: απλή λίστα με τα ονόματα της τάξης

### Εξαγωγή και εισαγωγή

Αποθηκεύστε μια τάξη σε αρχείο και φορτώστε την ξανά, στον ίδιο ή σε άλλον υπολογιστή.
Το αρχείο είναι πάντα κρυπτογραφημένο: κατά την εξαγωγή επιλέγετε έναν κωδικό τουλάχιστον
12 χαρακτήρων. Αν το αρχείο μπορεί να ανοιχτεί σε άλλον υπολογιστή, προτιμήστε λατινικά
γράμματα, γιατί ο κωδικός πρέπει να πληκτρολογηθεί ακριβώς όπως ορίστηκε.

Αν η τάξη υπάρχει ήδη στο Entaxy, η εισαγωγή δεν την αντικαθιστά ποτέ: το αρχείο
προστίθεται ως ξεχωριστή τάξη, με την ημερομηνία εισαγωγής στο όνομά της.

Μια τάξη που εισάγεται είναι πάντα κλειδωμένη, ώστε να μην αλλάξει κατά λάθος.
Ξεκλειδώστε τη από το μενού Τάξη όταν θέλετε να επεξεργαστείτε τα παιδιά της.

### Τα δεδομένα σας μένουν στη συσκευή σας

Το Entaxy δεν έχει διακομιστή ούτε λογαριασμό. Ό,τι καταχωρίζετε αποθηκεύεται μόνο στον
φυλλομετρητή σας, σε αυτή τη συσκευή, και δεν αποστέλλεται πουθενά.

Αυτό σημαίνει επίσης ότι:

- Αν διαγράψετε τα δεδομένα ιστοτόπων του φυλλομετρητή, διαγράφονται και οι τάξεις σας
- Οι τάξεις σας δεν μεταφέρονται μόνες τους σε άλλον φυλλομετρητή ή υπολογιστή.
  Χρησιμοποιήστε την εξαγωγή και την εισαγωγή για να τις μεταφέρετε
- **Κάνετε τακτικά εξαγωγή των τάξεών σας** ως αντίγραφο ασφαλείας. Το αρχείο είναι
  κρυπτογραφημένο, αφού περιέχει προσωπικά στοιχεία των παιδιών και των οικογενειών
  τους. Ένας χαμένος κωδικός δεν μπορεί να ανακτηθεί

## English

Entaxy is a simple class management app for teachers. It keeps the complete roster of a
class: the students, their guardians and how to reach them. The app is in Greek and
English.

### Classes and students

- One or more classes, each with its students' personal details, addresses, phone
  numbers and notes
- For each student, their guardians, how they are related to the student, and their
  contact details
- A class can be locked from the Class menu: its students can't be added, changed or
  removed until you unlock it from the same menu. A lock next to its name shows that it is
  locked. The class's name can still be changed

### Reports

- **Contacts catalog (pdf)**: a printable roster of the class with every guardian's
  phone numbers
- **Guardian emails (csv)**: the guardians' email addresses, without duplicates, ready
  for a mailing list

### Cards

- **Student grid (pdf)**: the students' names laid out in a grid to print and cut into
  cards, with 1, 2 or 3 names per row, optionally with last names, in bold or printed
  twice
- **Student list (pdf)**: a plain list of the class's names

### Export and import

Save a class to a file and load it back, on the same computer or another one. The file is
always encrypted: when you export, you choose a password of at least 12 characters. If the
file may be opened on another computer, prefer Latin letters, because the password has to
be typed exactly as it was set.

If the class is already in Entaxy, importing never replaces it: the file is added as a
separate class, with the import date in its name.

An imported class is always locked, so it can't be changed by accident. Unlock it from the
Class menu when you want to edit its students.

### Your data stays on your device

Entaxy has no server and no account. Everything you enter is stored only in your browser
on this device, and nothing is sent anywhere.

This also means:

- Clearing your browser's site data deletes your classes
- Your classes don't follow you to another browser or computer. Use export and import
  to move them
- **Export your classes regularly** as a backup. The file is encrypted, since it
  contains personal information about students and their families. A lost password
  cannot be recovered
